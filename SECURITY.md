# Security policy

## Reporting a vulnerability

Please report security problems privately. Don't open a public issue or discussion.

Open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and which version of PRAANA you tested (`praana --version`).

We aim to acknowledge a report within a few days and will keep you informed while we investigate and fix it.

## Supported versions

Security fixes are made in the latest release. Please update to the newest version before reporting.
