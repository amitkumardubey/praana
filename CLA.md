## How to sign

Add your GitHub username to `.github/CLA_SIGNERS.txt` (one username per line)
in a pull request separate from your code contribution, or add it in the same
PR that introduces your first contribution. The CI check
(`.github/workflows/cla-check.yml`) verifies that every commit author in a
PR has signed.

If you are making your first contribution, add your username to
`.github/CLA_SIGNERS.txt` and commit it in your PR. The CLA check will pass
once your username is in the file.
